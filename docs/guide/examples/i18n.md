# 国际化示例

本示例展示了如何使用带有国际化（i18n）支持的 ImagesViewer。

## 基本国际化

```javascript
const viewer = new ImagesViewer({
  images: ['image1.jpg', 'image2.jpg'],
  i18n: {
    info: {
      name: '名称:',
      dimensions: '尺寸:',
      shortcuts: '快捷键',
      zoomIn: '放大:',
      zoomOut: '缩小:',
      prev: '上一张:',
      next: '下一张:',
      reset: '重置:',
      fullscreen: '全屏:',
      info: '信息:',
      close: '关闭:'
    },
    buttons: {
      prev: '上一张 (←)',
      next: '下一张 (→)',
      close: '关闭 (Esc)',
      loading: '加载中...'
    }
  }
});
```

## 动态语言切换

### 语言检测

```javascript
// 检测用户语言
const userLanguage = navigator.language.split('-')[0]; // 获取语言代码（例如 'en', 'zh'）

// 语言翻译
const translations = {
  en: { /* 英语翻译 */ },
  zh: { /* 中文翻译 */ },
  // 添加更多语言
};

// 使用检测到的语言创建查看器
const viewer = new ImagesViewer({
  images: ['image1.jpg', 'image2.jpg'],
  i18n: translations[userLanguage] || translations.en // 默认为英语
});
```

### 语言选择器

```html
<select id="language-selector">
  <option value="en">English</option>
  <option value="zh">中文</option>
  <option value="es">Español</option>
  <option value="fr">Français</option>
</select>
<button onclick="changeLanguage()">切换语言</button>

<script>
  function changeLanguage() {
    const language = document.getElementById('language-selector').value;
    
    // 关闭现有的查看器（如果有）
    if (window.currentViewer) {
      window.currentViewer.close();
    }
    
    // 打开带有选定语言的新查看器
    window.currentViewer = new ImagesViewer({
      images: ['image1.jpg', 'image2.jpg'],
      i18n: translations[language]
    });
  }
</script>
```

## RTL 语言支持

对于阿拉伯语或希伯来语等从右到左的语言，您可能需要添加额外的 CSS：

```html
<!DOCTYPE html>
<html dir="rtl">
  <head>
    <title>ImagesViewer RTL 示例</title>
    <style>
      /* ImagesViewer 的 RTL 支持 */
      .images-viewer-container {
        direction: rtl;
      }
      
      .images-viewer-toolbar {
        flex-direction: row-reverse;
      }
      
      .images-viewer-info {
        text-align: right;
      }
    </style>
  </head>
  <body>
    <!-- 内容 -->
  </body>
</html>
```

## 最佳实践

### 翻译一致性

- 保持所有 UI 元素的翻译一致
- 使用母语人士验证翻译
- 考虑术语的文化差异

### 性能

- 只加载必要的翻译
- 考虑为不太常见的语言延迟加载翻译
- 缓存翻译以供重复使用

### 可访问性

- 确保翻译后的文本适合 UI 元素
- 在不同语言中使用屏幕阅读器测试
- 考虑 RTL 语言的文本方向
