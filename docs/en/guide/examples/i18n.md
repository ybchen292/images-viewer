# Internationalization Example

This example demonstrates how to use ImagesViewer with internationalization (i18n) support.

## Basic Internationalization

```javascript
const viewer = new ImagesViewer({
  images: ['image1.jpg', 'image2.jpg'],
  i18n: {
    info: {
      name: 'Name:',
      dimensions: 'Size:',
      shortcuts: 'Shortcuts',
      zoomIn: 'Zoom In:',
      zoomOut: 'Zoom Out:',
      prev: 'Previous:',
      next: 'Next:',
      reset: 'Reset:',
      fullscreen: 'Fullscreen:',
      info: 'Info:',
      close: 'Close:'
    },
    buttons: {
      prev: 'Previous (←)',
      next: 'Next (→)',
      close: 'Close (Esc)',
      loading: 'Loading...'
    }
  }
});
```

## Dynamic Language Switching

### Language Detection

```javascript
// Detect user language
const userLanguage = navigator.language.split('-')[0]; // Get language code (e.g., 'en', 'zh')

// Language translations
const translations = {
  en: { /* English translations */ },
  zh: { /* Chinese translations */ },
  // Add more languages
};

// Create viewer with detected language
const viewer = new ImagesViewer({
  images: ['image1.jpg', 'image2.jpg'],
  i18n: translations[userLanguage] || translations.en // Fallback to English
});
```

### Language Selector

```html
<select id="language-selector">
  <option value="en">English</option>
  <option value="zh">中文</option>
  <option value="es">Español</option>
  <option value="fr">Français</option>
</select>
<button onclick="changeLanguage()">Change Language</button>

<script>
  function changeLanguage() {
    const language = document.getElementById('language-selector').value;
    
    // Close existing viewer if any
    if (window.currentViewer) {
      window.currentViewer.close();
    }
    
    // Open new viewer with selected language
    window.currentViewer = new ImagesViewer({
      images: ['image1.jpg', 'image2.jpg'],
      i18n: translations[language]
    });
  }
</script>
```

## RTL Language Support

For right-to-left languages like Arabic or Hebrew, you may need to add additional CSS:

```html
<!DOCTYPE html>
<html dir="rtl">
  <head>
    <title>ImagesViewer RTL Example</title>
    <style>
      /* RTL support for ImagesViewer */
      .images-viewer-container {
        direction: rtl;
      }
      
      .images-viewer-toolbar {
        flex-direction: row-reverse;
      }
      
      .images-viewer-info {
        text-align: right;
      }
    </style>
  </head>
  <body>
    <!-- Content -->
  </body>
</html>
```

## Best Practices

### Translation Consistency

- Keep translations consistent across all UI elements
- Use native speakers to verify translations
- Consider cultural differences in terminology

### Performance

- Load only the necessary translations
- Consider lazy-loading translations for less common languages
- Cache translations for repeated use

### Accessibility

- Ensure translated text fits within UI elements
- Test with screen readers in different languages
- Consider text direction for RTL languages
